# Sponsor Usage

## Airbyte
Use for ingesting external signals:
- GitHub Issues
- Discussions
- Slack
- support / docs sources if needed

## ClickHouse
Use for:
- raw signal history
- deduplication outcomes
- agent step events
- test outcomes
- PR outcomes
- metrics over time

## Langfuse
Use for:
- agent traces
- tool calls
- prompt versions
- evaluation and debugging
- step-by-step observability

## Composio
Use for:
- GitHub issue creation
- PR creation
- comments
- Slack notifications

## Guild.ai
Use for multi-agent orchestration:
- intake
- dedup
- triage
- investigation
- testing
- PR creation

## Render
Use for hosting:
- frontend
- API
- worker

## TrueFoundry
Use for:
- agent execution
- evaluation pipelines
- safe deployment of fix generation workflows

## OpenUI
Use for the dashboard shell and operator surface.
