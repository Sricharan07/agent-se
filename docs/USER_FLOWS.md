# User Flows

## 1. Onboarding
1. Log in with GitHub.
2. Select one repository.
3. Connect signal sources.
4. Choose the primary focus.
5. Review permissions.
6. Start monitoring.

## 2. Incoming signals
A Slack message, GitHub issue, or discussion appears in the unified intake feed.

## 3. Deduplication
The system merges related signals into one canonical issue.

## 4. Investigation
The agent begins step-by-step analysis, shown in detailed logs.

## 5. Validation
Tests run and results are captured.

## 6. Draft PR
The system creates a draft PR and writes a summary.

## 7. Learning
A successful investigation can be saved as a reusable procedure.
