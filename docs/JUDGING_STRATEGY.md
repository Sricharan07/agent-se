# Judging Strategy

## Idea
Frame it as autonomous software evolution, not an issue tracker.

## Technical implementation
Highlight:
- ingestion
- deduplication
- agent orchestration
- detailed logs
- PR generation
- validation

## Tool use
Show at least three sponsors naturally:
- Airbyte
- ClickHouse
- Langfuse
- Composio
- Guild.ai

## Presentation
Use a single, clean story:
Signal -> Cluster -> Investigate -> Test -> PR -> Learn

## Autonomy
The key point:
the user does not tell the agent which issue to work on.
The system finds, groups, and prioritizes work on its own.
